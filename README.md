# Job Salary Analysis
Analysis of a data science job vacancies dataset to explore the dependence of salaries on various factors. Visualization and development of a regression model. 

Project Overview: The project involved data cleaning (removal of unnecessary data, handling and imputing missing values), feature engineering, and exploratory data analysis with comprehensive visualizations. To categorize unclassified job postings, an NLP pipeline (TF-IDF + LightGBM Classifier) was trained based on raw text descriptions. Finally, an XGBoost regression model was developed, with feature importance visualized to highlight the key factors identified by the model.
